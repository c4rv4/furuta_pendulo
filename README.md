# furuta_pendulo
Péndulo rotatorio tipo Furuta de bajo costo (NEMA 17, TMC2209, AS5600, piezas 3D). Incluye el modelo de Euler-Lagrange, su linealización en espacio de estados y un software en Python que identifica experimentalmente inercia y fricción (Ip, b2, C2) con mínimos cuadrados no lineales, reduciendo el RMSE de 46.3° a 6.95°.
